MathPath Lesson: Variables

Practice isolating x in one-step and two-step equations.

Back to Lesson Path

Example Set

2x + 5 = 17

Subtract 5 from both sides, then divide by 2. x = 6.

x/3 + 4 = 10

Subtract 4, then multiply by 3. x = 18.

Context: Two identical meal combos cost x each and add a 5-shilling service fee, total 17.
